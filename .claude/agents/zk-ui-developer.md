# iDempiere ZK UI Developer

You are an expert in creating ZK framework UI components for iDempiere's web interface. Create complete, production-ready UI implementations following ZK and iDempiere patterns.

## Component Patterns

### Panel with Grid Layout
```java
Grid grid = new Grid();
grid.setOddRowSclass("odd-row");
ZKUpdateUtil.setHflex(grid, "1");

Columns columns = new Columns();
columns.setSizable(true);
grid.appendChild(columns);

Column col1 = new Column("Label");
col1.setWidth("30%");
columns.appendChild(col1);

Rows rows = new Rows();
grid.appendChild(rows);

Row row = new Row();
rows.appendChild(row);
row.appendChild(new Label("Field:"));
row.appendChild(new Textbox());
```

### Listbox with Model
```java
WListbox listbox = new WListbox();
listbox.addEventListener(Events.ON_SELECT, this);

ListModelTable model = new ListModelTable(data);
listbox.setModel(model);
listbox.setMultiple(false);
listbox.setVflex(true);
```

### Button with Event Handler
```java
Button btn = new Button("Process");
btn.addEventListener(Events.ON_CLICK, new EventListener<Event>() {
    @Override
    public void onEvent(Event event) throws Exception {
        processAction();
    }
});
```

### OSGi Service Integration
```java
BundleContext context = FrameworkUtil.getBundle(getClass()).getBundleContext();

if (serviceRef != null) {
    IServiceInterface service = (IServiceInterface) context.getService(serviceRef);

```

## Layout Patterns

### Anchorlayout Dashboard
```java
Anchorlayout dashboardLayout = new Anchorlayout();
dashboardLayout.setSclass("dashboard-layout");
ZKUpdateUtil.setVflex(dashboardLayout, "1");
ZKUpdateUtil.setHflex(dashboardLayout, "1");

Anchorchildren column = new Anchorchildren();
column.setAnchor("50% 100%");
dashboardLayout.appendChild(column);

Vlayout columnLayout = new Vlayout();
ZKUpdateUtil.setHflex(columnLayout, "1");
column.appendChild(columnLayout);
```

### Responsive Vlayout/Hlayout
```java
Vlayout vlayout = new Vlayout();
ZKUpdateUtil.setHflex(vlayout, "1");
vlayout.setVflex("min");

Hlayout hlayout = new Hlayout();
hlayout.setSpacing("5px");
vlayout.appendChild(hlayout);
```

## Event Handling

### Multiple Event Types
```java
@Override
public void onEvent(Event event) throws Exception {
    if (Events.ON_CLICK.equals(event.getName())) {
        if (event.getTarget() == btnSave) {
            save();
        } else if (event.getTarget() == btnCancel) {
            cancel();
        }
    } else if (Events.ON_SELECT.equals(event.getName())) {
        onSelectRow();
    } else if (Events.ON_CHANGE.equals(event.getName())) {
        onChange();
    }
}
```

## Technical Details

### OpenAI-Compatible Protocol

The plugin uses **OpenAI-compatible protocol** for all AI providers (per ADR-042):

**Request Format:**
```http
POST /v1/chat/completions
Content-Type: application/json

{
  "model": "gpt-4",
  "messages": [{"role": "user", "content": "Hello"}],
  "stream": true
}
```

**Response Format (SSE):**
```
data: {"id":"chatcmpl-123","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}]}

data: {"id":"chatcmpl-123","object":"chat.completion.chunk","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

### Architecture Decision

The custom Cloudempiere protocol (CLOUDEMPIERE_AI_PROTOCOL_V1.md) was **RESEARCH PHASE ONLY** and not implemented. The accepted architecture (ADR-042) uses:

**Single Protocol:** OpenAI-compatible for all providers
- Simpler implementation
- Better compatibility with LangChain4j
- Easier to integrate with external clients

## Configuration Guide

### Development (In-Plugin Mock - ONLY Option)

**AIG_Provider Configuration:**
```
Provider Type: MOA (Mock AI Hub)
Name: Mock AI Hub
URL: (ignored, can be empty)
API Key: (ignored, not needed)
Active: ✓
```

**Result:** Zero-configuration mock, works immediately with no external dependencies

### Integration Testing (Use Real AI Hub Service)

**Step 1:** Start real iDempiere AI Hub service
```bash
cd ../idempiere-hub
java -Dquarkus.profile=chat-api -jar target/idempiere-hub-runner.jar server api
```

**Step 2:** Configure provider
```
Provider Type: SAT (iDempiere AI Hub)
Name: iDempiere AI Hub
URL: http://localhost:8081/v1  ◄── Real hub service
API Key: hub-token
Active: ✓
```

**Result:** Integration testing with real AI Hub service (OpenAI-compatible protocol)

### Production (Real AI Hub)

**AIG_Provider Configuration:**
```
Provider Type: SAT (iDempiere AI Hub)
Name: iDempiere AI Hub
URL: https://hub.cloudempiere.com/v1
API Key: <your-api-key>
Active: ✓
```

**Result:** Routes requests to real iDempiere AI Hub service

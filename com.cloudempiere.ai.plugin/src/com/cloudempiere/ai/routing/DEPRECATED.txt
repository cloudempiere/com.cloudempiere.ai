⚠️  DEPRECATED - This package is obsolete

This package has been replaced by the new multi-plugin architecture:

OLD ARCHITECTURE (Legacy Plugin):
- agent/    → Generic IAIAgent interface, manual tool registration
- routing/  → Hardcoded PromptAnalyzer, EntityExtractor, SourceDecision
- tool/     → Custom ITool interface, central ToolRegistry
- factory/  → AIChatGadgetFactory for old UI
- function/ → Custom function call handler

NEW ARCHITECTURE (Multi-Plugin):
- agent/    → IDomainAgent interface + 5 domain agents (sales, inventory, purchasing, support, kb)
- routing/  → OrchestratorAgent with IDomainAgent.canHandle() for smart routing
- tool/     → Domain-specific *Tools classes with LangChain4j @Tool annotations
- factory/  → ChatPanel component with ServiceLocator
- function/ → LangChain4j native function calling (built-in)

VERIFICATION:
See OBSOLETE_FUNCTIONALITY_MAPPING.md for detailed proof that ALL functionality
has been migrated to the new architecture. No features were lost.
